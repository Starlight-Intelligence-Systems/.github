# Starlight Intelligence Systems

**Knowledge should survive a change of model.**

This organization holds Starlight's protocol and research projects on portable context, agent coordination and inspectable intelligence systems. The [Starlight Intelligence organization](https://github.com/Starlight-Intelligence) is the developer and community entry point. Follow each repository's declared source while organization ownership is reconciled.

Led by [Frank Riemer](https://github.com/frankxai), we develop reference architectures and evaluation methods that other builders can study, challenge and improve.

## Collaborate on a question worth testing

We welcome researchers, engineers and educators who can contribute a reproducible experiment, a careful critique or a reference implementation. Useful work makes its assumptions, method and limitations visible.

For a research collaboration, implementation workshop or joint technical demonstration, contact [frank@frankx.ai](mailto:frank@frankx.ai).

## Contribution standard

Follow the owning repository's instructions and license. Keep proposed behavior separate from measured results, and submit changes to the canonical source where an organization repository is a mirror.
